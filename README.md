# Cloud-Based Bus Pass System

## About the Project
The Cloud-Based Bus Pass System is a web application that helps users apply for and manage bus passes online. It reduces paperwork and makes the bus pass process easier and faster.

## Features
- Online bus pass application
- View bus pass details
- Manage bus pass applications
- Simple and user-friendly interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite

## Project Objective
The main objective of this project is to simplify the bus pass application process using web technology and database management.

## Internship
This project was developed as part of the CodeAlpha Cloud Computing Internship.
